Overview

TCG Inventory is a personal collection tracker for Pokémon cards. You import CSV exports from Dex (manually or via Dropbox sync), and the app computes everything else — unique cards, duplicates, value, and collection/rarity/series breakdowns — directly from what you actually own. None of this is stored twice: everything is recalculated from your cards every time a page loads, so duplicate counts and total value can never drift out of sync with each other.

Dashboard

The front page shows your collection broken down several ways at once:

  • Value growth — a simplified version of the chart in Transactions's "View charts" section (only the "Unique collection" metric, no filter). See Transactions for the full picture.
  • Top 10 most valuable cards — your ten most expensive individual cards by price.
  • Inventory — Collections (named groupings) and Bulk (cards with no collection) side by side, with a total row at the top.
  • Series — breakdown per series (e.g. Scarlet & Violet), sorted by release order. Click a series row to see the sets in that series, and a set to see the cards in it.
  • Rarity — breakdown per rarity tier, sorted from Common to the rarest (Secret Rare at the top of the rarity scale).
  • Pokemon — see Pokemon folders below.

Every row can be expanded ("▶") to see the individual cards behind the number — useful for seeing exactly which prints make up a collection, a set, or a rarity group.

Pokemon folders (favorites and merging)

The Pokemon card on the Dashboard groups all your cards by Pokemon name, not by exact print — "how much Sableye do I have", not "how much of this exact set".

Favorites: search for a Pokemon in the search box at the top of the card and click the star to add it to the Favorites table, which always shows regardless of whether the Pokemon is in the top 10 or not. Click the star again to remove it.

Merge into a folder: under "Put Pokemon in the same folder" you can put several names into the same folder — either because they're the same Pokemon under a different print name (e.g. Celebi and Dark Celebi), or because you want to see a whole evolution family together (e.g. Slowpoke, Slowbro, and Slowking in one folder). This only changes the display here on the Dashboard — your cards, prices, and CSV export are never affected. Every merge can be undone with the "Undo" button in the folder list.

If a folder contains cards from several different sets/series, the Set/Series column shows "Multiple" (hover to see which) instead of a single name.

Sorting

Every table in the app sorts the same way: click a column header to sort ascending, click again for descending (the arrow ▲/▼ shows the current direction). For tables with expandable rows (Collections, Series, Rarity), sorting a column only reorders the cards inside a row — the rows themselves (collection/series/set/rarity) always keep their fixed order. For flat top lists (Top 10 most valuable cards, Pokemon Top 10), sorting reorders the rows themselves.

Inventory

Your whole collection as one big, searchable table. The search box matches name, card ID, number, and illustrator. The dropdowns filter by series, set, collection, binder, and language (e.g. ENG/JPN — which language/region print the card is). "Duplicates only" links from the Dashboard bring you here pre-filtered. Card names link on to the card on Dex.

Transactions

New Purchase/Sale: click the button to start — the app reserves the next free Order ID automatically. Then search for each card that was part of the deal and add them one by one; each row can be priced individually, or left blank and use "Distribute evenly across empty prices" to split a remaining amount equally across the cards without a price yet. "Remove" takes a card back out of the order before you register. Every card in the list shares the same Order ID and date/platform when you click "Register". An optional "Agreed total" can also be set at registration time, or later from inside the order group itself in History — it then shows as "registered / agreed / diff", so you can see how much of what you actually paid isn't yet assigned to a specific card (typically common cards not priced individually yet).

"Recently Added" shows cards with a Date column for when they were first imported, with a quick form to register the purchase price (and an optional Order ID) directly on each card — pre-filled again if you've already registered one price for that card. Cards with no known import date (from before this feature existed) are grouped in a sealed "Unknown date" section at the bottom.

Above History, a compact financial summary is shown: net invested, current value, and paper gain/loss (color-coded green/red), calculated from actual recorded transactions — not estimates. "View charts" opens two charts (fetched lazily on first click): "Collection value growth" is an approximation — it applies today's price to the date each card was added, since Dex provides no historical price data, and has a filter (Unique collection / Duplicates / Total) that switches between showing the value of unique cards only, duplicates only, or the sum of both. "Purchases and sales per month" is real figures, however, not an approximation. Both charts have a "View as table" link with the underlying numbers.

"History" shows every recorded transaction as a compact row (date, card, type, price, platform). Transactions sharing the same Order ID — typically several cards bought together in a lot — are grouped into their own collapsible group with a count and total, instead of showing as separate rows. Transactions without an Order ID show separately under "Individually registered".

Sync Log

This page shows the history of sync runs — daily automatically via a Vercel Cron job against Dropbox, or triggered manually by an administrator (see README for setup). It's read-only: uploading a CSV or browsing Dropbox no longer happens from this page, only from the underlying API routes the cron and an administrator use directly. A normal sync flags cards missing from the export instead of deleting them — only a "Full load" actually deletes cards no longer in the "My Collection" export.

Frequently asked questions

Why doesn't the duplicate count match what I expect?
Duplicates are counted as quantity − 1 per unique card (card_id + variant). Two different variants of the same card (e.g. "Normal" and "Poké Ball Holo") count as two separate cards, not duplicates of each other.
I merged the wrong Pokemon — can I undo it?
Yes — open "Put Pokemon in the same folder" and click "Undo" next to the name you want to separate back out.
Why isn't a column sortable?
Some columns show a value that isn't unambiguous per row (e.g. Set/Series when a Pokemon folder spans several sets) and are therefore plain text instead of a sort link.
Where does the daily sync run?
As a Vercel Cron job against /cron/dropbox-sync, protected by a secret in the CRON_SECRET environment variable — see README for setup.
