Agreed total defaults to shipping + the cards already priced, but type over it with what you actually paid for the order, then use "Distribute remaining across unpriced cards" to spread the difference over the ones you haven't priced individually (price 0) — useful for a lot where you know a few cards' values and want the rest to absorb the remainder. "By market value" gives each card a share proportional to its current price (a card with no price gets the average share); "Evenly" gives every card the same amount. Either way the cents add up exactly to the remainder. With "Include shipping" on, the cards you already priced keep their price and the unpriced ones absorb the rest including shipping — Shipping is set to 0 because it now lives in those cards' prices, so it's never counted twice. With it off, shipping stays a separate line and is split across all the order's cards by price. This doesn't save until you click "Save changes" below.

Moving a row to a different Order ID clears this order's agreed total/shipping for that row — set the destination order's total/shipping afterward from the Transactions page, it's never guessed or split automatically.
